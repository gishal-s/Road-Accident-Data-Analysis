# Road Accident Data Analysis

## Project Overview

This project is an Excel-based data analytics project focused on analyzing road accident data and identifying important patterns and trends.

The analysis uses Excel features such as **Power Query, PivotTables, PivotCharts, KPIs, filters, and an interactive dashboard** to summarize and visualize the accident data.

## Objective

The main objective of this project is to analyze road accident data and understand patterns related to:

- Accident frequency
- Accident trends
- Accident severity
- Locations
- Time-based patterns
- Casualties and injuries
- Other available accident-related factors

## Tools Used

- Microsoft Excel
- Power Query
- PivotTables
- PivotCharts
- Excel Dashboard
- Filters / Slicers
- Data Cleaning and Transformation

## Project Workflow

**Raw Dataset → Data Cleaning → Data Analysis → PivotTables → Charts → Dashboard → Insights**

## Data Analysis

The project uses PivotTables and charts to analyze the accident dataset based on the available fields.

The analysis includes:

- Accident count analysis
- Accident trends
- Accident severity analysis
- Location-based analysis
- Time-based analysis
- Casualty/injury analysis
- Other relevant factors available in the dataset

## Dashboard

An interactive Excel dashboard was created to present the analysis in a simple and visual format.

The dashboard contains:

- KPI cards
- Charts
- PivotCharts
- Filters / Slicers
- Key accident-related insights
